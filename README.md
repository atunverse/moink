# 墨印 · MoInk

> **把喜欢的瞬间，放在身边。**
> 基于 ESP32-C3 与华为拆机四色电子墨水屏（768×552，黑 / 白 / 黄 / 红）的电子拍立得、桌面相框与随身挂件。

墨印是一台可以随身携带的「电子拍立得」：手机连上设备热点，在网页里完成**选图 → 裁剪 → 风格化 → 文字排版**，一键推到 768×552 的四色墨水屏上。断电后画面**永久保持**，静态几乎零功耗。

- **不用装 App**：设备自带热点与门户引导页，连上即自动弹出创作页
- **不用服务器**：图像合成都发生在浏览器里，设备只负责「收帧 → 刷屏 → 睡觉」
- **不连网也能用**：默认纯热点模式；想让它自己上网 / 转发，接进路由器即可（R1.3.5 起）

## 🛠️ 技术要点

- **画面合成 100% 在浏览器端**：固件只做热点 / 接收 / 刷图 / 休眠 / 唤醒 / 升级，Flash 占用约 79.8%（1,045,392 B / 1,310,720 B），RAM 14.3%，给页面与轮播留出余量
- **帧协议严格**：16 字节帧头（魔数 / 版本 / 面板 / 尺寸 / CRC16-CCITT-FALSE）+ 2bpp 载荷（768×552 → 105,984 B），设备端逐字节校验并做几何自洽检查，坏帧直接拒绝
- **三重自愈**：控制页 CRC32 校验失败自动回退内嵌副本；OTA 双分区 + 防降级；升级**不重置**用户设置
- **并发安全**：刷屏 / 残影清理共用帧缓冲互斥锁；HTTP 上传全链喂电源看门狗，避免「传图中途睡着」
- **门禁齐全**：`check_algo.py`（逐像素一致性）、`check_frame.py`（帧协议 + 打包布局）、`smoke_page.js`（页面结构与契约同步）三道闸，改完必须全绿

## 📦 硬件清单

| 部件 | 规格 |
|------|------|
| 主控 | ESP32-C3 SUPERMINI（RISC-V 单核，160 MHz，无 PSRAM） |
| 屏幕 | 华为拆机 768×552 四色电子墨水屏（JD79665AA，黑/白/黄/红，2bpp） |
| 唤醒按键 | 接 GND，低电平有效；单击唤醒、双击切图、长按 20 秒恢复出厂 |
| 电池检测 | ADC 分压 1M:1M（×2.0），ADC 端建议并联 100 nF 到地 |
| 供电自锁 | GPIO2 → MOS 栅极（自锁维持供电 / 关机切断） |

### 接线（三档预设，页面「GPIO 设置」里选）

| 信号 | 默认档 | 排线档 | 整合板档 |
|------|--------|--------|----------|
| SCK | GPIO4 | GPIO7 | GPIO4 |
| MOSI(DIN) | GPIO6 | GPIO10 | GPIO3 |
| CS | GPIO7 | GPIO6 | GPIO5 |
| DC | GPIO1 | GPIO5 | GPIO6 |
| RST | GPIO3 | GPIO4 | GPIO7 |
| BUSY | GPIO10 | GPIO3 | GPIO10 |
| 唤醒键 | GPIO5 | GPIO1 | GPIO1 |
| 电池 ADC | GPIO0 | GPIO0 | GPIO0 |
| 自锁 | GPIO2 | GPIO2 | GPIO2 |

> 也可以选「自定义」逐个挑脚：仅 GPIO0..10 可用且避开自锁脚 GPIO2；ADC 只能选 GPIO0–4，唤醒键只能选 GPIO0–5。**改引脚需重启生效**，改错按住唤醒键 20 秒可恢复出厂。

## 🚀 快速开始

详细步骤看 **[新手入门教程](docs/入门教程.md)**，这里只列三条路：

```bash
# A. 自己编译（Python 3.9+ / PlatformIO）
python -m platformio run -e moink
python tools/flash_moink.py

# B. 用现成刷机包：解压 flash_kit/ 里的包，双击 bat
# C. 到 GitHub Releases 下载最新的 MoInk-FlashKit-*.zip
```

刷完手机连热点 **`MoInk-XXXX`**（XXXX = MAC 后 2 字节），浏览器会自动弹出创作页；没弹就手动访问 `http://192.168.4.1`。

## 📖 日常使用

1. **连接**：上电建热点 → 手机连接 → 自动弹出创作页（或访问 `http://192.168.4.1`）
2. **拍立得**：选图 → 裁剪构图 → 选风格 / 留白 / 文字 → 「上传并刷新屏幕」
3. **便签**：切到「便签」→ 输文字 → 调字体颜色描边底色 → 上传
4. **轮播**：「上传到图库」占一个槽位（最多 8 张），设备端双击按键切下一张
5. **设置**：右上角 ⚙ —— 设备信息 / 电源管理 / 热点 / 联网 / 屏幕 / GPIO / 系统维护与升级
6. **按键**：单击 = 唤醒（不切图）；双击 = 切下一张；长按 20 秒 = 恢复出厂

## ⚡ 供电与电池安全（★ 用老排线务必升级到 R1.3.6）

老版 FPC 排线上，电池经两只背靠背 AO3401 接到 VSYS，栅极由 GPIO2 驱动。旧固件上电**无条件拉高自锁**，于是插 USB 时 5 V 会直接压在电芯 / 充电管理芯片的 BAT 脚上 —— 倒灌 3~4 A 且无 CC/CV，有发热、鼓包的隐患。

R1.3.6 起固件改为「**先判断怎么上的电，再决定要不要自锁**」：

- **冷启动只认按键**：电池到 VSYS 的唯一通路是按住按键，USB 上电没人按键 ⇒ 按键已松即判「USB 供电」，不自锁。
- **运行中每 200 ms 采一次 ADC**，连续 3 次 > 4.5 V 才释放自锁（600 ms 内切断电池）。
- **新排线**（CH213K 理想二极管反向阻断、ADC 接 VSYS）在页面勾选「新排线」后**不再做插入检测**：插着线时保持供电，拔线不掉电。
- **老排线在电池供电下不允许休眠**（超时一律按「关机」处理）：深睡期间插 USB，芯片没有任何手段发现。

**行为代价（务必知道）**：

- USB 供电下不持有电池 ⇒ **拔线即断电**，要按键开机（按键需按住到开机，约 0.3 秒）。
- 接法选错时电池开不了机（安全方向的退化）：先插 USB 进页面选对接法。
- 老排线电池供电不再休眠，定时唤醒随之失效。

> 硬件侧建议：新排线把一只 AO3401 换成 **CH213K 理想二极管**做反向阻断，充电走独立 **4057**（VSYS → 电池），ADC 分压改接 **VSYS**。软硬兼施后插拔 USB 完全无感。

## ⚠️ 硬约束（改代码前必读）

- **色码固定**：`0x00=黑 0x01=白 0x02=黄 0x03=红`（实测标定，与部分参考实现相反）
- **几何固定**：帧缓冲为逻辑图 180° 旋转存储，`packIdx` 与驱动严格对应；X 方向编码镜像 `enc_x = 768-x-w`
- **固件不做图像处理**：所有像素由页面在浏览器端合成完毕才发送
- **不要加蓝牙**：C3 无 PSRAM，蓝牙会挤占 WiFi 缓冲
- **版本号一套**：`src/version.h` 的 `MOINK_VERSION` 与页面 `<meta name="moink-page-version">` 必须一致，改页面后必须重跑 `make_index_header.py`
- **api 号与版本号解耦**：只有帧头字段 / 偏移 / 载荷契约变化才 +1（当前 api = 2）
