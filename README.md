# 墨印 · MoInk

> **把喜欢的瞬间，放在身边。**
> 基于 ESP32-C3 与华为拆机四色电子墨水屏（768×552 黑/白/黄/红）的电子照片 / 电子拍立得 / 挂件。

墨印 · MoInk 是一台可以随身携带的「电子拍立得」：手机或电脑连接设备热点后，在网页里完成**选图 → 裁剪 → 风格化 → 文字排版**，一键推送到 768×552 的华为拆机四色墨水屏（黑/白/黄/红）上。断电后画面**永久保持**，功耗极低，适合做成桌面相框、冰箱贴或随身挂件。

- **不用 App**：设备自带 WiFi 热点与 captive portal，手机连上即自动弹出创作页面
- **不用服务器**：所有图像合成在浏览器本地完成，设备只负责「接收 → 刷屏 → 睡觉」
- **长续航**：传图完成即深度睡眠，GPIO5 按键唤醒，静态几乎零功耗

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🖼️ 四色电子照片 | 黑/白/黄/红四色墨水屏（华为拆机 768×552 屏），支持拍立得白边、文字叠加 |
| ✂️ 浏览器内裁剪 | 内嵌 Cropper.js：捏合缩放、自由旋转、90° 贴合、EXIF 方向自动摆正 |
| 🎨 eink-warm 暖调算法 | 专为四色屏设计的色彩映射 + 8 种误差扩散抖动算法，肤色自然不偏红 |
| ✏️ 所见即所得文字编辑 | 多文字对象、拖动/缩放/旋转/描边/底色，画布实时渲染，四色文字直出 |
| 📱 响应式双模式 | 拍立得（图像为主）/ 便签（文字为主）双模式；手机单列、桌面双栏预览 |
| 🔁 页面热更 | 创作页面可不刷固件单独 OTA 更新，CRC32 校验失败自动回退内嵌页 |
| ⚙️ 设备管理 | 热点名称/密码修改、休眠时间、残影清理、恢复出厂、电池电压检测 |
| 🔋 低功耗 | 传图后自动深度睡眠（Deep Sleep），按键唤醒，适配电池供电挂件形态 |

## 🛠️ 技术亮点

- **画面合成 100% 在浏览器端**：固件只做「热点 / 接收 / 刷图 / 休眠 / 唤醒 / OTA」，保持极小体积（Flash 占用约 60%），页面通过页面热更通道独立迭代
- **eink-warm 图像算法（逐行冻结）**：饱和度幂律映射 + 线性光抖动，解决四色屏「肤色发红」「画面发白」两大通病；有跨语言（Python/JS）逐像素一致性门禁 `check_algo.py`（12/12 MATCH）
- **严谨的帧协议**：16 字节帧头（魔数 / 版本 / 面板 / 尺寸 / CRC16-CCITT-FALSE）+ 105,984B 载荷，设备端逐字节校验，坏帧直接拒绝
- **三重自愈**：页面 CRC32 校验失败自动回退内嵌副本；OTA 双分区 + 防降级；恢复出厂逐键擦除保留页面热更标记
- **并发安全**：刷屏 / 残影清理共用帧缓冲互斥锁；HTTP 上传全链喂电源看门狗，避免「传图中途深睡」

## 📦 硬件清单

| 部件 | 规格 |
|------|------|
| 主控 | ESP32-C3 SUPERMINI（RISC-V 单核，无 PSRAM） |
| 屏幕 | 华为拆机 768×552 四色电子墨水屏（黑/白/黄/红，2bpp） |
| 唤醒按键 | GPIO5 → GND（低电平，长按 5s 恢复出厂） |
| 电池检测 | GPIO0（ADC1_CH0，470k:100k 分压） |
| 屏幕接线 | SCK=4 / MOSI=6 / CS=7 / DC=1 / RST=3 / BUSY=10 |

## 🚀 快速开始

详细步骤请看 **[新手入门教程](docs/入门教程.md)**，这里只列关键三步：

```bash
# 1. 编译固件（需要 Python + PlatformIO）
python -m platformio run -e moink

# 2. USB 刷机（或直接用 flash_kit/ 一键刷机包）
python tools/flash_moink.py

# 3. 手机连接设备热点 MoInk-XXXX，浏览器自动弹出创作页
```

也可以免编译直接使用 `flash_kit/` 目录里的一键刷机包（含预编译固件；没装 Python 会引导自动安装），或到 [GitHub Releases](https://github.com/atunverse/moink/releases) 下载刷机包。

## 📖 使用方法

1. **连接**：设备上电后创建热点 `MoInk-XXXX`（XXXX 为 MAC 后 2 字节），手机连接后自动弹出创作页（或浏览器访问 `http://192.168.4.1`）
2. **拍立得模式**：选图 → 裁剪调整 → 可选风格/留白/文字 → 「上传并刷新屏幕」
3. **便签模式**：直接输入文字（可加描边、底色、四色字体）→ 上传
4. **设备设置**：主页右上角 ⚙ 进入 —— 热点改名、休眠时间、残影清理、恢复出厂
5. **更新**：设置页支持页面热更（HTML 单文件）与固件 OTA（.bin）

```

│   ├── main.c            #   主入口：初始化 / 循环 / 睡眠与唤醒

│   ├── frame.c           #   帧协议接收与校验（CRC16）
│   ├── ota_web.c         #   HTTP 服务 / OTA / 页面热更（CRC32 自愈）
│   ├── netif_ap.c        #   纯 SoftAP 网络接口
│   ├── captive.c         #   captive portal DNS
│   ├── settings.c        #   NVS 设置存储
│   └── power.c           #   电源管理 / 电池 ADC / 深睡
├── page/                 # 创作页面（单文件 HTML，可独立热更）
│   ├── index.html        #   当前工作版本
│   └── vendor/           #   内嵌第三方库（Cropper.js v1.6.2）

│   ├── check_algo.py     #   算法冻结比对（逐像素一致性门禁）
│   ├── smoke_page.js     #   页面结构冒烟测试
│   ├── make_index_header.py  # 页面 → C 头文件（固件内嵌）
│   ├── flash_moink.py    #   USB 刷机
│   └── package_bins.py   #   打包发布 bin
├── flash_kit/            # 一键刷机包（含预编译固件，免编译体验）

├── platformio.ini        # PlatformIO 配置（env=moink）
└── CHANGELOG → docs/CHANGELOG.md
```

## ⚠️ 硬件与固件约定

- **色码固定**：`0x00=黑 0x01=白 0x02=黄 0x03=红`（实测标定，与部分参考实现相反，改动前必读 `docs/CONTRACT.md`）
- **几何固定**：帧缓冲为逻辑图 180° 旋转存储，`packIdx` 与驱动严格对应
- 固件**不做任何图像处理**——所有像素由页面在浏览器端合成完毕后才发送
- 请勿在固件中添加蓝牙（ESP32-C3 无 PSRAM，蓝牙会挤占 WiFi 缓冲）
