# 墨印 MoInk 更新说明（R1.3.5 / R1.3.6）

1. **安全修复（R1.3.6，用老排线的机器务必升级）**：旧固件插 USB 时 5 V 会顺着自锁电路灌进电池。
   现在只有按着按键开机才自锁，插 USB 开机不自锁；运行中插线 0.6 秒内自动释放自锁。
2. **新排线在设置里勾一次「新排线」**：插着线也保持供电、拔线不断电。老排线用电池时不再休眠，到点直接关机。
3. **能连家里的 WiFi（R1.3.5）**：最多记 8 个网络，开机自动连；手机连设备热点也能上网。默认关闭，去页面打开。
4. **大图预览可直接「显示到屏幕」**：不用回图库再双击切图。

> 两版分区表一致，网页 OTA 或线刷均可；刷回上一版从 Release 下载对应 `moink_R*.bin` 即可。
