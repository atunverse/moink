# 墨印 · MoInk — 传输与驱动契约（CONTRACT）

> 本文档是**固件与页面之间的唯一权威接口定义**，以及**屏驱动的物理契约**。
> 改动任何一条必须同步更新 `check_frame.py` / `smoke_page.js` 并全量回归。
> 版本：api = 1，fw = R1.0.0，page = R1.0.0。

---

## 1. 帧格式 v1（`POST /api/frame`）

整帧上传，**无局部刷新**。请求体 = 16 字节头（大端）+ 2bpp 载荷。

| 偏移 | 长度 | 字段 | 值 |
|---|---|---|---|
| 0–1 | 2 | 魔数 | `0xA5 0x5A` |
| 2 | 1 | 格式版本 | `1`（api = 1） |
| 3 | 1 | 面板类型 | `0`=A0 / `1`=A1（**仅信息性**，实际面板由设备设置决定，不随帧切换） |
| 4–5 | 2 | 宽（大端） | `768` |
| 6–7 | 2 | 高（大端） | `552` |
| 8–11 | 4 | 载荷长度（大端） | `105984` |
| 12–13 | 2 | CRC16（大端） | CRC-16/CCITT-FALSE，仅对载荷字节计算 |
| 14–15 | 2 | 保留 | `0` |

- 载荷：768×552 的 **2bpp** 位图，`768/4 × 552 = 105984` 字节。
- CRC 算法：**CRC-16/CCITT-FALSE** — poly `0x1021`，init `0xFFFF`，无反射、无终异或（非 CCITT/IBM 反射变体）。黄金测试向量：`"123456789"` → `0x29B1`。
- 校验顺序：魔数 → 版本 → 宽高 → 载荷长度 → 流式收载荷并累加 CRC → CRC 比对。任一失败返回 `400`；缓冲被占用（上一帧正在刷）返回 `500 busy`。

## 2. 2bpp 位图编码

- 每字节 4 像素，**MSB 优先**：像素 `x` 位于字节内位 `(6 - 2*(x%4))`。
- 色码（A0 实测，与部分参考实现相反）：
  | 2bit 值 | 颜色 |
  |---|---|
  | `00` | 黑 K |
  | `01` | 白 W |
  | `10` | 黄 Y |
  | `11` | 红 R |
- 纯色整屏字节值：黑 `0x00`、白 `0x55`、黄 `0xAA`、红 `0xFF`。

## 3. 180° 几何契约（缓冲 ↔ 逻辑图）

缓冲与逻辑图像呈 **180° 旋转**关系（页面在浏览器里合成时已按此契约打包，固件只原样写屏）：

- 缓冲第 `r` 行 = 逻辑图像第 `y = H-1-r` 行（**自下而上**存储）。
- 每行内像素从左到右仍按 `x` 升序填充，但字节内 2bit 组序也倒（见 §2 的位映射）。
- 逻辑图 `(0,0)`（左上角）落在缓冲**最后一个字节的低 2 bit**。

页面的 `packIdx()` 与固件 `epd_display_2bpp()` 必须严格对应；`check_frame.py` 的 180° 放置断言即是此契约的黄金校验。

## 4. 屏画像：A0 / A1

| 项 | A0 | A1 |
|---|---|---|
| 分辨率 | 768×552 | 768×552 |
| 枚举值 | `0` | `1` |
| Y 映射 | **隔行半屏**：`j < H/2 ? j*2 : 2*(H-j)+(-1)`（`lower_y_base = -1`） | 整窗线性，单次 0x10 写入，**不隔行**（`lower_y_base = 0`） |
| 初始化 | 标准 A0 初始化路径 | JD79665 式（0xAA 解锁 + 0x65/0x84 级联），BUSY 窗口 180s |
| 验证状态 | ✅ 已上机 | ⚠️ 未上机，留 `hflip` 兜底 |

- 面板切换**运行时生效，无需重刷**，且**不能随帧切换**（帧头 hdr[3] 仅信息性）。
- 显示名：`epd_panel_name()` 返回 `"A0"` / `"A1"`。

## 5. 引脚映射

| 信号 | GPIO |
|---|---|
| SCK | 4 |
| MOSI | 6 |
| CS | 7 |
| DC | 1 |
| RST | **3** |
| BUSY | 10 |
| 唤醒键 | 5 → GND（内部上拉，低电平唤醒；长按 5s 恢复出厂） |
| 电池 ADC | 0（ADC1_CH0；ADC2 与 WiFi 冲突不可用） |

- 电池分压 470k:100k，`Vbat = Vpin × 570 / 100`，满量程 3100 mV @ 12 dB。

## 6. HTTP API 路由（`api = 1`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 控制页（web 分区优先，否则内嵌页） |
| GET | `/api/info` | 状态 JSON：fw/page/api/panel/heap/bat_mv/sleep_s/wake_s/clients/ssid/uptime |
| GET | `/api/settings` | 读设置 JSON：panel/hflip/sleep_s/wake_s/ssid/pass_set |
| POST | `/api/settings` | 写设置（`panel`/`hflip`/`sleep_s`/`wake_s`，`ssid`+`pass` 成对） |
| POST | `/api/frame` | 传图（§1 帧格式） |
| POST | `/api/ota` | 固件升级（写另一槽 + 切换 + 45s 确认） |
| POST | `/api/web` | 页面热更（擦写 web 分区 + CRC32 + 提取版本 meta） |
| POST | `/api/web/clear` | 清空 web 分区（回到内嵌页） |
| POST | `/api/clear` | 残影清理（可选 `cycles` 1–4） |
| POST | `/api/factory` | 恢复出厂 + 重启 |
| OPTIONS | `*` | CORS 预检（离线客户端走 file://） |

## 7. 设置与 NVS

- 命名空间 `moink`；键 `panel` / `hflip` / `sleep_s` / `wake_s` / `ap_ssid` / `ap_pass`。
- 休眠档位（`sleep_s`）：`0`=不休眠 / `60` / `180`（默认）/ `300` 秒。
- 定时唤醒档位（`wake_s`）：`0`=关（默认）/ `3600` / `43200` / `86400` 秒。
- 热点：SSID 空 → 默认 `MoInk-XXXX`（XXXX = MAC 后 2 字节）；密码空 → **开放**。AP 通道 1，最多 4 客户端，DHCP DNS 指向 `192.168.4.1`。
- 页面自身所有画面参数（风格 / 强度 / 文字 / 旋转 / 方向）一律存于手机 `localStorage`（key `moink.cfg4`，历史键自动一次性迁移），**固件不存、不回读**。

## 8. 版本判定流程

- 固件接口 `api` 不变时，页面升级**只走 `/api/web`**，无需重刷固件。
- 页面改动若触碰 §1–§6 任一契约，则 `api` 需 +1，并强制重刷固件。
- 回归门禁（必须全绿）：
  - `python tools/check_frame.py`（帧契约黄金校验）
  - `node tools/smoke_page.js`（页面纯函数 + 帧头 + 旋转 + 文字层几何）
  - `python tools/check_algo.py`（算法冻结，12 函数逐字 MATCH）
