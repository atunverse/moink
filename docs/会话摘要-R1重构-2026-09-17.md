# 会话摘要 — MoInk R1 重构：开发 → 上机验收 → 热修迭代 → 基线固化

> 会话时间：2026-09-16 ～ 2026-09-17　|　产物基线：**fw R1.0.6 + page R1.0.10**
> 本文为该阶段的结构化摘要；逐版本变更细节见 `docs/CHANGELOG.md`，回退材料见 `moink/backups/`。

## 一、讨论主题

1. **R1 一次性重构开发**：以 M5/M7 为参照全新重写固件与页面（禁照抄，理解式重写），编译前回归前置，一次刷机上机验收。
2. **上机验收与热修迭代**：12 个上机暴露问题的定位与修复（详见 §三）。
3. **OTA 与页面体系完善**：页面固定地址 OTA、本地预览模式、CORS/预检体系。
4. **工程机制建立**：协作约定（先方案后实施）、CHANGELOG 版本记录、基线固化（releases/）。

## 二、已确认的关键决策

| 决策 | 内容 |
|---|---|
| 版本规则 | api=1 恒定；fw 与 page **独立递增**——页面改动不碰固件接口只热更，碰接口则两侧同步+刷机/OTA |
| 固件职责 | 只做热点/接收/刷图/休眠/唤醒/OTA；画面全部由页面在浏览器合成；不再加图像处理与蓝牙 |
| 开发流程 | **页面先在离线把图像跑通（四色预览出图）再上传/OTA**——页面内置 previewOK 硬闸强制执行 |
| OTA 体系 | 页面 OTA 目标固定 `http://192.168.4.1/api/ota`（纯 SoftAP IP 恒定）；跨源 CORS 已配齐（通配 URI 匹配 + ACAO 头 + 简单请求发送） |
| 协作约定 | 反馈问题 → 先分析原因/方案/风险 → 用户确认 → 最小化实施 + `backups/` 备份 + 回退步骤（通用适用） |
| 记录机制 | `docs/CHANGELOG.md`：任何 fw/page 改动必须新增条目（版本/日期/新增/修改/修复/涉及文件/影响范围），最新在上 |
| 基线版本 | **fw R1.0.6 + page R1.0.10** 固化于 `releases/baseline-fwR1.0.6_pageR1.0.10/`（固件+页面+源码快照） |

### 3.2 上机热修链（12 个问题全部闭环）
| # | 现象 | 真根因 | 修复版本 |
|---|---|---|---|
| 1 | 页面底部漏 JS 源码、设置不加载 | 导出函数字符串含字面量 `</script>` 终结主脚本 | page R1.0.1 |
| 2 | /api/web 上传断连「net」 | httpd 栈 4KB 内放 12KB 数组爆栈 | fw R1.0.2 |
| 3 | 缩略图裂图/部分内核画不出图 | blob URL onload 立即 revoke | page R1.0.2 |
| 4 | 传图上传被锁死前的兜底 | 预览门禁缺失 | page R1.0.3 |
| 5 | 页面热更后变"静态壳" | flash 增量写入跨未擦扇区静默损坏 | fw R1.0.4 |
| 6 | 图像白板（PC/手机一致） | 舞台 `#src` 误写 `<img>`（应 `<canvas>`），管线第一步即死 | page R1.0.5 |
| 7 | 上传图变形 | createImageBitmap resize 参数是强制绝对尺寸 | page R1.0.6（移除预压缩） |
| 8 | 文字被底色盖图/文字被抖动 | drawTextLayer 无条件 fill 底色；图文未分层处理 | page R1.0.6（noBg + renderComposite 分层） |
| 9 | 恢复出厂后页面回退内嵌版 | nvs_erase_all 连带擦页面热更标记 | fw R1.0.3 |
| 10 | 电池电压乱跳 | ADC 悬空杂散漂移；跨请求状态机判「未连接」 | fw R1.0.3 + page R1.0.7 |
| 11 | 本地页面 OTA 报 net | OPTIONS * 通配路由在默认精确匹配下不生效（预检 404） | fw R1.0.6 + page R1.0.10（简单请求） |
| 12 | /api/info 页面版本 fallback 陈旧 | PIO IDF 不跟踪 version.h 隐式依赖 | fw R1.0.7（CMake OBJECT_DEPENDS） |
