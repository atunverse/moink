单张模式：地址直接填一个 .bin 的完整 URL；清单模式：地址填目录， 设备读其中的 moink.mf 逐张轮播（第一行必须是 MOINKMF1， 之后每行「文件名 CRC32」，CRC32 可省）。
开启后，定时唤醒 / 双击按键会优先取远程；取不到自动回退本地槽，屏幕不会白。
读只要一个普通静态地址即可（nginx / 对象存储 / GitHub 直链都行），不用架服务； 写（「存到远程」）用的是标准 HTTP PUT + Basic 认证，任何接受 PUT 的服务都能收， 不限于 WebDAV（群晖、坚果云、Nextcloud、自建脚本都可以），纯静态目录收不了 PUT。
只支持 http://（本版不做 TLS）。地址、账号改完点「保存」才写入设备。
屏幕
屏幕上下颠倒着安装时勾选：输出时把画面旋转 180°，点一下即生效，不用重启。预览与图库缩略图仍按正向显示。
2 次黑白全屏闪刷，约 40~60 秒
GPIO
已被其它项占用的 IO 会自动从下拉里去掉。电池 ADC 只能选 GPIO0–4，唤醒键只能选 GPIO0–5。
引脚改动需重启才生效。改错导致屏不亮时，按住唤醒键 20 秒可恢复出厂。
更新和恢复
选 .bin 固件上传：控制页随固件一并更新，设置重置、热点名与密码保留，设备自动重启。
