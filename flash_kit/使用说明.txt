墨印 MoInk 一键刷机包
版本：R1.3.6（固件与控制页共用同一个版本号；2026-11-11，api 保持 2）
================================================

★★★ 使用老排线（R1.3.1 版 FPC，电池经两只 AO3401 直连 VSYS）的机器，
   务必升级到本版 —— 旧固件插 USB 时会把 5V 倒灌进电池（3~4A，无 CC/CV）。
   新排线 / 默认档杜邦线接法的机器也建议升级，但没有这层安全隐患。

本版主要变化：
  ① ★★★ 供电来源判定（安全修复）—— 上电只认「有没有按按键」：按键开机才自锁，
                 插 USB 开机不自锁；运行中每 200ms 测一次电压，连续 3 次
                 高于 4.5V 立即切断电池通路；老排线在电池供电下不再休眠
  ② 页面新增「排线版本」勾选项（接法 = 排线时才出现）：勾了「新排线」就不做
     插入检测（CH213K 已反向阻断、ADC 接 VSYS），插着线也不切断电池
  ③ 关机时先解除 GPIO 保持再拉低，修掉「深睡唤醒后再也关不掉」的隐患

（R1.3.5 的联网 / 热点转发 / 门户窗口、R1.3.4 的 O(1) 删图与电池读数、
  R1.3.2 的按键语义与唤醒来源、R1.3.1 的排线档引脚改版，都仍在当前版本中。）

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.3.6_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.3.6_app.bin     OTA 升级包（设备已能开机时，在网页里上传）
  page-R1.3.6.html         创作页面（网页里「升级」上传，免刷机）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）

怎么升到本版
------------------------------------------------
★ 本版分区表与帧格式都没变，从 R1.2.0 及之后的版本可以**直接网页 OTA**，
  不必线刷。只有 R1.2.0 之前的旧版本（R1.1.x 及更早）才必须用方式 B 线刷。

【推荐】方式 A：设备现在跑 R1.2.0 及之后（含 R1.3.0 ~ R1.3.5），网页里直接升
  1. 控制页「设置 → 系统维护与升级」，把 moink_R1.3.6_app.bin 选进去
  2. 等设备重启完成（约 1 分钟）
  3. 重启后页面自动变成新版（控制页随固件一并更新），版本显示 R1.3.6。
     ★ 你已有的设置（屏型 / 休眠档 / 发射功率 / 热点 / GPIO 接法 / 联网）
       以及轮播图都还在。

方式 B：需要整包刷写 / 首次使用 / 从 R1.1.x 及更早升级
  1. 双击 MoInk一键刷机.bat。如果这台电脑没有 Python，
     会询问「是否自动下载并安装」，输入 y 回车即可。
  2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。
  3. 双击 MoInk一键刷机.bat，等它自动选串口、自动刷写（约 1~2 分钟）。
     脚本只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）会自动跳过。
  4. 看到 [OK] 刷机完成即可。手机 Wi-Fi 连 MoInk-XXXX（默认开放）→
     浏览器打开 http://192.168.4.1

※ 方式 B 是整包覆盖写，会连分区表一起重写（相当于恢复出厂）。
※ 只想清掉设备里已有的轮播图，不用刷机：网页「设备轮播图库 → 清空轮播」即可。

★★★ 老排线 / 新排线：升级后必须确认这一项（安全相关）
------------------------------------------------
老排线的问题：电池经两只背靠背 AO3401 接到 VSYS，栅极由 GPIO2 控制。
旧固件上电就无条件拉高自锁，于是插 USB 时 5V 顺着自锁通路直接压在电芯 /
充电管理芯片的 BAT 脚上 —— 倒灌 3~4A 且没有 CC/CV。

本版怎么处理：
  · 冷启动只判断「按键是否被按住」。电池到 VSYS 的唯一通路就是按住按键；
    插 USB 上电没人按键 ⇒ 判为 USB 供电，不自锁。
  · 自锁状态下每 200ms 采一次 ADC，连续 3 次 > 4500mV 才释放自锁（约 600ms）。
  · 「设置 → 电源管理 → 排线版本」：接法选「排线」时出现。
      - 不勾（默认）＝老排线：电池供电时**不允许休眠**，超时一律按「关机」处理。
        原因：睡着的芯片没有任何手段发现 USB 插入（C3 的 ULP 访问不到 SAR ADC）。
      - 勾选＝新排线（CH213K 理想二极管反向阻断、ADC 接 VSYS）：**不做插入检测**，
        插着线也保持电池通路，拔线不掉电，休眠与定时唤醒都正常。

升级后要做的：
  · 用老排线：什么都不用勾（默认就是老排线）。代价是电池供电不再休眠，
    要省电请手动关机（拔掉 USB 后按长按 20 秒恢复出厂以外的正常关机流程，
    即「超时动作 = 关机」）。
  · 用新排线：进页面 → 电源管理 → 勾上「新排线」→ 保存电源设置。

★ 已知行为变化（务必知道）
  · USB 供电时设备不持有电池 ⇒ **拔掉 USB 就断电**，需要按一下开机键。
  · 开机键要按到开机完成（约 0.3 秒）；按太短会表现为「按了没反应」，
    这是安全方向的退化，不是故障。
  · 接法选错时电池开不了机：先插 USB 进页面把接法选对，再拔线用电池。

★ 排线接法（本版未改，与 R1.3.1 一致）

  信号        排线档        默认档
  ADC          GPIO0         GPIO0
  KEY（唤醒）   GPIO1         GPIO5
  LOCK（自锁）  GPIO2         GPIO2   （固定，不在这八个脚里）
  BUSY         GPIO3         GPIO10
  RST          GPIO4         GPIO3
  DC           GPIO5         GPIO1
  CS           GPIO6         GPIO7
  SCK          GPIO7         GPIO4
  DIN(MOSI)    GPIO10        GPIO6

★ 若你是用「自定义」档手工填的脚位，升级后请按实际接线复核一遍，否则不亮屏。
※ 改动 GPIO 必须重启才生效（SPI 总线与 ADC 通道只在开机时初始化），
  所以选完请点「保存并重启」。

★ GPIO 设置怎么用
------------------------------------------------
「设置 → GPIO 设置」四档：
  · 默认    —— 出厂杜邦线（SCK=4 DIN=6 CS=7 DC=1 RST=3 BUSY=10，唤醒=5，ADC=0）
  · 排线    —— SCK=7 DIN=10 CS=6 DC=5 RST=4 BUSY=3，唤醒=1，ADC=0
  · 整合板  —— SCK=4 DIN=3 CS=5 DC=6 RST=7 BUSY=10，唤醒=1，ADC=0
  · 自定义  —— 逐个下拉选 IO。已选过的 IO 会自动从其它下拉里去掉，避免撞车；
              电池 ADC 只能选 GPIO0~4（C3 的 ADC1 固定绑这几脚），
              唤醒键只能选 GPIO0~5（深睡只有这几个脚能唤醒）。
※ GPIO2 固定留给 MOS 自锁，不在这八个脚里出现。
※ 改错导致屏不亮：按住唤醒键 20 秒可恢复出厂。

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  网页烧录器（WebSerial）会卡死在 "Stub running..."，一个字节都写不进。
- 如果卡死或失败：拔插一次 USB，然后在本目录打开命令行运行：
      python flash_on_pc.py --no-stub
- 查看本机全部串口：
      python flash_on_pc.py --list

★ 关于电量显示（分压比是写死在固件里的）
------------------------------------------------
本包固件按 **×2.0 分压** 标定电量 —— 100k:100k 与 1M:1M 的比值相同，
两种电阻都能直接用，固件系数（BAT_DIV_NUM/DEN = 200/100）不用改。

电量判定为一次请求内连采 12 次取中位数，再用最大减最小的极差判断悬空。
打开控制页应直接出电压，不必刷新几次。

⚠️ 新排线的 ADC 接在 **VSYS** 上：插着 USB 时读数会接近 5V，这是正常现象，
   不代表电池满电（此时读的是供电母线，不是电芯）。

⚠️ 若用 1M:1M（源阻抗约 500 kΩ），ADC 端建议并联 100 nF 到地。
   若读数与万用表差得多，按实测重标 `src/power.c` 的 `BAT_FULLSCALE_MV`
   （当前 3100 mV）。

刷完验证
------------------------------------------------
控制页「设置 → 设备信息」应显示：版本 R1.3.6 / 接口 2。

□ V1（★本版重点）电池按键开机：
   拔掉 USB，用电池 + 按住开机键约 1 秒 → 屏幕点亮、热点出现；
   松手后设备**不应掉电**。此时「设备信息」里能看到电池电压。

□ V2（★本版重点）完全关机状态插 USB 不倒灌：
   设备完全关机（或拔掉电池开关）→ 插 USB → 用万用表量电池端电压，
   **不应升到 5V**（应在电池自身电压附近）。
   这一步是本版的存在意义，老排线务必实测一次。

□ V3（★本版重点）运行中插 USB：
   电池供电运行中（已自锁）→ 插 USB → 600ms 内串口/日志出现释放自锁；
   屏幕与热点不受影响；拔掉 USB 设备会断电（预期行为）。

□ V4（★本版重点）新排线勾选：
   接法 = 排线 + 勾「新排线」→ 插着 USB 时保持供电，**拔线不应断电**；
   超时后能正常休眠、定时唤醒也能醒来。

□ V5（★本版重点）老排线禁休眠：
   接法 = 排线 + 不勾「新排线」，用电池供电，超时设 1 分钟、动作选「休眠」→
   等 1 分钟设备应**关机断电**（而不是睡过去）。

□ V6 复位不误自锁：
   插着 USB 时在页面点「保存并重启」→ 重启后不应自锁（不插线时拔线仍会断电）。

□ V7 刷屏与四色：传一张彩色照片，四色显示正确、方向正常、无白边错位。

□ V8 电量读数：接电池时与万用表相符（误差 5% 以内可接受）。

□ V9 轮播：传 2 张以上进图库 → 双击按键切下一张；单击只唤醒不切图。

□ V10 升级兼容：用 moink_R1.3.6_app.bin 网页 OTA，升级后轮播图与设置都在。

□ V11 关机：超时动作选「关机」→ 到点完全断电（需自锁电路），
    按键无法唤醒，需重新按开机键。

升级不兼容说明（重要）
------------------------------------------------
- 本版固件仍**没有** /api/ota 与 /api/web（R1.2.0 起删除）：R1.1.x 的旧页面
  无法升级本版设备，请使用本包里的页面。
- 反过来，R1.1.x 固件的设备上也没有 /api/upload：若把本包页面热更到
  那些设备再点升级，页面会提示「设备固件过旧，不含统一升级入口」——
  请先按方式 A / B 把固件升到 R1.2.0 及以上。
- **升级不重置用户设置**（屏型 / 左右镜像 / 休眠 / 唤醒 / 发射功率 /
  GPIO 接法 / 联网配置），热点名与密码保留。
- ⚠️ 从 R1.1.x 升到 R1.2.x 及以后必须**线刷（方式 B）**，不能 OTA：R1.2.0 分区表有变
  （新增 store 存储分区），分区表只能整包线刷改写。R1.2.0 及之后可正常 OTA。
- 恢复内置页面按钮仍在（设置页「升级」下方），用于把热更的控制页清掉、
  回到固件内置的那一份。
- 本版新增 NVS 键 `line_v`（排线版本）。老设备没有该键 → 默认「老排线」，
  即安全侧（电池供电不休眠）。新排线用户升级后需要手动勾一次。
