墨印 MoInk 一键刷机包
版本：R1.3.5（固件与控制页共用同一个版本号；2026-11-03，api 保持 2）
================================================

本版主要变化：
  ① ★ 图库预览可以直接上屏 —— 点缩略图打开大图预览，按「显示到屏幕」
                设备就切到这张，之后双击按键从这张接着往下轮
  ② ★ 选了「关机」不再被定时唤醒 —— 没装自锁电路时关机会退回休眠，
                旧版仍按之前设的「自动唤醒」定时醒来切图，本版已修复

（R1.3.4 的删除提速与电量读数修复、R1.3.3 的电源管理与定时唤醒切图、
  R1.3.2 的按键语义与唤醒来源、R1.3.1 的排线档引脚改版，都仍在当前版本中。）

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.3.5_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.3.5_app.bin     OTA 升级包（设备已能开机时，在网页里上传）
  page-R1.3.5.html         创作页面（网页里「升级」上传，免刷机）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）

怎么升到本版
------------------------------------------------
★ 本版分区表与帧格式都没变，所以从 R1.2.0 及之后的版本可以**直接网页 OTA**，
  不必线刷。只有 R1.2.0 之前的旧版本（R1.1.x 及更早）才必须用方式 B 线刷。

【推荐】方式 A：设备现在跑 R1.2.0 及之后（含 R1.2.2 / R1.3.0 ~ R1.3.4），网页里直接升
  1. 控制页「设置 → 系统维护与升级」，把 moink_R1.3.5_app.bin 选进去
  2. 等设备重启完成（约 1 分钟）
  3. 重启后页面自动变成新版（控制页随固件一并更新），版本显示 R1.3.5。
     ★ 你已有的设置（屏型 / 休眠档 / 发射功率 / 热点 / GPIO 接法）都还在；
     ★ 已经存在的轮播图也还在（store 分区不受升级影响）。

方式 B：需要整包刷写 / 首次使用 / 从 R1.1.x 及更早升级
  1. 双击 MoInk一键刷机.bat。如果这台电脑没有 Python，
     会询问「是否自动下载并安装」，输入 y 回车即可。
  2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。
  3. 双击 MoInk一键刷机.bat，等它自动选串口、自动刷写（约 1~2 分钟）。
     脚本只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）会自动跳过。
  4. 看到 [OK] 刷机完成即可。手机 Wi-Fi 连 MoInk-XXXX（默认开放）→
     浏览器打开 http://192.168.4.1

※ 方式 B 是整包覆盖写，会连分区表一起重写（相当于恢复出厂）。
※ 只想清掉设备里已有的轮播图，不用刷机：网页「设备轮播图库 → 清空轮播」即可。

★ 排线接法有变（本版重点，接错了会不亮屏）
------------------------------------------------
本版的「排线」档按新排线重新分配，与 R1.3.0 及更早**不同**：

  信号        新排线档      旧排线档（R1.3.0 及更早）
  ADC          GPIO0         GPIO0
  KEY（唤醒）   GPIO1         GPIO5   ← 变了
  LOCK（自锁）  GPIO2         GPIO2   （固定，不在这八个脚里）
  BUSY         GPIO3         GPIO1   ← 变了
  RST          GPIO4         GPIO3   ← 变了
  DC           GPIO5         GPIO4   ← 变了
  CS           GPIO6         GPIO6
  SCK          GPIO7         GPIO7
  DIN(MOSI)    GPIO10        GPIO10

★ 用排线接法的板子：升级后**必须重新确认 GPIO 档位**——
  若升级前选的就是「排线」档，档位号没变（仍为第 2 档），会自动套用新表，
  按新接线接好即可；**但如果是用「自定义」档手工填的旧脚位，
  升级后必须进页面按新接线重选一遍**，否则不亮屏。
※ 改动 GPIO 必须重启才生效（SPI 总线与 ADC 通道只在开机时初始化），
  所以选完请点「保存并重启」。

★ GPIO 设置怎么用
------------------------------------------------
「设置 → GPIO 设置」四档：
  · 默认    —— 出厂接线（SCK=4 DIN=6 CS=7 DC=1 RST=3 BUSY=10，唤醒=5，ADC=0）
  · 排线    —— SCK=7 DIN=10 CS=6 DC=5 RST=4 BUSY=3，唤醒=1，ADC=0（本版改版）
  · 整合板  —— SCK=4 DIN=3 CS=5 DC=6 RST=7 BUSY=10，唤醒=1，ADC=0
  · 自定义  —— 逐个下拉选 IO。已选过的 IO 会自动从其它下拉里去掉，避免撞车；
              电池 ADC 只能选 GPIO0~4（C3 的 ADC1 固定绑这几脚），
              唤醒键只能选 GPIO0~5（深睡只有这几个脚能唤醒）。
※ GPIO2 固定留给 MOS 自锁，不在这八个脚里出现。
※ 若你的设备是「排线」或「整合板」接法、且之前从 R1.2.1 及更早升上来，
  NVS 里可能还没有 GPIO 记录 → 会暂时落在「默认」档：进页面选对应档、
  点一次「保存并重启」即可，之后再升级不会复现。

硬件提醒（自锁脚）
------------------------------------------------
R1.2.2 起 GPIO2 被用作 MOS 一键开机自锁脚，上电后固件立即拉高、深睡前锁存电平。
  · 没有接自锁电路的板子：GPIO2 悬空或被固件拉高，不影响开机与显示。
  · 接了自锁电路：请按外部电路设计接，勿把 GPIO2 强拉低。

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  网页烧录器（WebSerial）会卡死在 "Stub running..."，一个字节都写不进。
- 如果卡死或失败：拔插一次 USB，然后在本目录打开命令行运行：
      python flash_on_pc.py --no-stub
- 查看本机全部串口：
      python flash_on_pc.py --list

★ 关于电量显示（分压比是写死在固件里的）
------------------------------------------------
本包固件按 **×2.0 分压** 标定电量 —— 100k:100k 与 1M:1M 的比值完全相同，
两种电阻都能直接用，固件系数（BAT_DIV_NUM/DEN = 200/100）不用改。

本版的「未连接」判定改成**一次请求内连采 12 次取中位数**，再用最大减最小
的极差判断引脚是否悬空（悬空时读数会乱飘、极差极大）。所以打开控制页
就该直接出电压，不必再刷新几次。

若换算出奇一致的「未连接」、或与万用表差得多，按实测值重新标定
`src/power.c` 的 `BAT_FULLSCALE_MV`（当前 3100 mV @ 12 dB）；
若板子用的是别的分压比（例如此前的 470k:100k = ×5.7），需改
`BAT_DIV_NUM` / `BAT_DIV_DEN` 后重新编译。

⚠️ 若仍用 1M:1M（源阻抗约 500 kΩ），ADC 端建议并联 100 nF 到地，
否则高阻源下读数会偏低、抖动偏大。

刷完验证（十二项）
------------------------------------------------
控制页「设置」设备状态应显示：版本 R1.3.5 / 接口 2。

□ V1 排线档引脚（★本版重点）：
   把板子设成「排线」档 → 点「保存并重启」→ 重启后能正常刷屏、
   四色显示正确、方向正常。若黑屏/白屏，先核对接线是否按上表。

□ V2 电量读数：
   接上电池，控制页电量百分比与万用表实测电压相符（误差 5% 以内可接受）。
   1M 高阻源若读数明显偏低，按上面说明并 100 nF 电容或重新标定。

□ V3 轮播抽检（R1.3.0 功能，抽检即可）：
   传一张图 → 屏幕显示且图库出现缩略图；短按按键切到下一张。

□ V4 升级兼容：
   本版直接用 moink_R1.3.5_app.bin 网页 OTA（分区表未变）；
   升级后已有的轮播图与设置都应保留。

□ V5 电源管理 - 休眠：
   「超时」设 1 分钟、「超时动作」选「休眠」→ 保存 → 静置 1 分钟，
   设备应进入深睡（热点消失）；按键可唤醒。

□ V6 电源管理 - 关机（★需自锁电路）：
   「超时」设 1 分钟、「超时动作」选「关机」→ 保存 → 静置 1 分钟，
   设备应完全断电（热消失、按键无法唤醒，需重新按开机键上电）。
   若设备只是休眠（按键还能唤醒），说明板上没有自锁电路，属预期限制。
   ★ 本版起这种情况下**不会再被定时唤醒**（见 V11）。

□ V7 定时唤醒切图：
   图库放 2 张以上，「自动唤醒」设 1 小时、勾选「唤醒后切图」→
   定时醒来后屏幕应切到下一张；取消勾选则保持原图不动。

□ V8 删除轮播图（R1.3.4）：
   图库放满 8 张 → 删第 1 张，应在 1 秒内完成（旧版要等约 10 秒）；
   剩下的图顺序正确前移、不缺张不重张；
   再传 1 张新图应落到末尾；断电重启后顺序不变。

□ V9 电量显示（R1.3.4）：
   打开控制页，「设备信息 → 电量」应立即显示读数（不再需要刷几次）；
   连刷几次页面读数稳定，不出现「未连接」。

□ V10 上传通道分离（R1.3.4）：
   先看「图库」页显示的张数 → 点「上传并刷新屏幕」换一张图：
   屏幕应刷新，而图库张数不变（这张图不进轮播、不占槽位）；
   再点「上传到图库」：图库张数 +1、屏幕不动；双击设备按键能轮到它。

□ V11 关机模式不再定时唤醒（★本版重点，用没装自锁电路的板子测）：
   先选「休眠」并把「自动唤醒」设成任意档 → 保存；再把「超时动作」改成
   「关机」→ 保存 → 静置到超时。设备退回休眠后应**一直不自己醒来**，
   只能按键唤醒（串口日志里 deep sleep 那行应是 timer 0s）。

□ V12 预览「显示到屏幕」（★本版重点）：
   图库放 2 张以上 → 点一张不是「当前」的缩略图打开大图预览 →
   点「显示到屏幕」：提示「已发送到屏幕，正在刷新…」，屏幕刷完后变成「✓ 屏幕已显示这张」，
   同时图库「当前」框移到这张（不用刷新页面）；再双击按键应切到它的下一张。

本版主要更新
------------------------------------------------
- ★ 图库大图预览新增「显示到屏幕」按钮（新接口 POST /api/carousel/show），
  设备立即切到预览的这张，并作为轮播的当前张。
- ★ 修复「超时动作」选「关机」后仍被定时唤醒：没有自锁电路时关机会退回休眠，
  旧版仍沿用之前设的「自动唤醒」间隔；本版只有选「休眠」时才开定时唤醒。
- 版本号升 R1.3.5；api 保持 2，帧格式与分区表零变动，可从 R1.2.0 及之后直接网页 OTA。

R1.3.4 主要更新
------------------------------------------------
- ★ 删除轮播图不再搬移数据：改为 NVS 里的 1 字节有效位图（alive），
  删除 = 清一位 + 计数减一，一次原子提交。满库删第一张从约 10 秒
  （擦写约 896 KB）降到 20 ms 以内，flash 零擦写。
  新图优先追加到末尾，末尾已满才回填最早的空洞。
- ★ 电池电压改为一次请求内连采 12 次取中位数，并用极差判断悬空，
  打开页面即出读数；不再依赖跨请求的「连续 3 次有效」。
- ★ 「上传并刷新屏幕」改为只换画面、不进图库（不占槽、不磨损 flash）；
  「上传到图库」才占用一个轮播位。临时换图不再挤掉轮播图。
- ★ 删除 / 清空失败原因分开返回：越界 404、设备正忙 503、存储异常 500，
  不再一律 400；页面删除期间按钮置灰，避免连点导致误删。
- 轮播列表与整图读取改为「逻辑序号 → 物理槽」换算，物理槽有空洞也不错位。
- 升级自动迁移：老设备按「前 N 槽有效」生成位图，与旧布局逐槽等价，
  已有轮播图不会丢；位图与计数不一致时以位图为准自动修正。
- 版本号升 R1.3.4；api 保持 2，帧格式与分区表零变动。

升级不兼容说明（重要）
------------------------------------------------
- 本版固件仍**没有** /api/ota 与 /api/web（R1.2.0 起删除）：R1.1.x 的旧页面
  无法升级本版设备，请使用本包里的页面。
- 反过来，R1.1.x 固件的设备上也没有 /api/upload：若把本包页面热更到
  那些设备再点升级，页面会提示「设备固件过旧，不含统一升级入口」——
  请先按方式 A / B 把固件升到 R1.2.0 及以上。
- **升级不重置用户设置**（屏型 / 左右镜像 / 休眠 / 唤醒 / 发射功率 /
  GPIO 接法），热点名与密码保留。唯一例外见上面「方式 A」里说的首次 GPIO 落档。
- ⚠️ 从 R1.1.x 升到 R1.2.x 及以后必须**线刷（方式 B）**，不能 OTA：R1.2.0 分区表有变
  （新增 store 存储分区），分区表只能整包线刷改写。R1.2.0 及之后可正常 OTA。
- 恢复内置页面按钮仍在（设置页「升级」下方），用于把热更的控制页清掉、
  回到固件内置的那一份。
