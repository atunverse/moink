墨印 MoInk 一键刷机包（在其他电脑上刷机用）
基线版本：fw R1.1.0 + page R1.1.0（2026-09-22，api 1 → 2）
================================================

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.1.0_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.1.0_app.bin     OTA 升级包（设备已能开机时，在网页「设置」里上传）
  page-R1.1.0.html         创作页面（网页「设置」里「页面热更」上传，免刷机）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）

首次使用步骤
------------------------------------------------
1. 双击 MoInk一键刷机.bat。如果这台电脑没有 Python，
   会询问「是否自动下载并安装」，输入 y 回车即可：
   自动从 python.org 下载官方安装包静默安装（约 25 MB），装完自动继续。
   已装过 Python 的电脑会直接进入下一步。
   第一次刷机还会自动 pip 安装 esptool，之后不再需要。

2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。

3. 双击 MoInk一键刷机.bat，等它自动选串口、自动刷写（约 1~2 分钟）。
   脚本只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）会自动跳过。

4. 看到 [OK] 刷机完成即可。设备重启后：
   手机 Wi-Fi 连接热点 MoInk-XXXX（默认开放）→ 自动弹出控制页，
   或浏览器打开 http://192.168.4.1

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  网页烧录器（WebSerial）会卡死在 "Stub running..."，一个字节都写不进。
- 刷整包会整体覆盖设备上的现有固件。
- 如果卡死或失败：拔插一次 USB，然后在本目录打开命令行运行：
      python flash_on_pc.py --no-stub
- 查看本机全部串口：
      python flash_on_pc.py --list

刷完验证
------------------------------------------------
1. 手机 Wi-Fi 出现 MoInk-XXXX，连接后能打开控制页。
2. 控制页「设置」里设备状态固件版本显示 R1.1.0（页面版本 R1.1.0）。
3. 传一张图，屏幕应在约 15~25 秒内完成刷新。

★ A1 屏四档驱动验收（本次重点，FB-010）
------------------------------------------------
适用：A1 批次屏（编号 A1，图像左右镜像 / 照片有细密条纹的那批）。
若你的屏是 A0（一直显示正常）或 A1.1（中间有黑线），**不用管这一节**。

操作路径：控制页「设置」→「屏幕设置」→「屏幕选择」选 A1
          → 下方出现「A1 驱动」下拉（共 4 档）。
用同一张【非对称测试图】逐档上传、逐档拍照记录（推荐素材：
samples/FB-010/测试图片/01_非对称方向图.png，图上带文字 + 箭头 + 四角编号）。

  档位                        期望结果
  --------------------------  --------------------------------------------
  3 方案D 相位1（默认）        ★ 正解。图像完整、方向正确、无穿插条纹。
                              后续日常就用这一档。
  4 方案D 相位2               若档 3 能显示但"上下半屏内容对调/错位"，改试
                              这一档，二选一定案。
  1 方案A 原生800×600·顺序    诊断档。按可见区裁切（右下内容被切掉），
                              画面会明显不对，仅作对照，不用它出图。
  2 方案A′ 原生800×600·交错   诊断档。同上几何，仅映射改交错。

判定要点：
  - 方向：图上文字可读、四角编号位置正确 → 方向对；
          文字左右反 → 勾选「左右镜像」再试；仍不对请反馈照片。
  - 穿插条纹：画面没有"上下半屏互相穿插""细密横纹" → 正确；
              若档 3 有、档 4 无（或反之）→ 定档 4。
  - 白边/裁切：可见区应被画面铺满、无白边、无内容被裁掉。
  - 选中档位后点「保存」，改档即时生效（无需重刷固件）。

页面与固件版本关系（重要）
------------------------------------------------
- 本版 api 由 1 升到 2：固件能接受旧页面的 768×552 帧（不会立刻失效），
  但「A1 驱动」下拉只在页面读到 api >= 2 时才出现。
- 若页面显示不出「A1 驱动」，说明页面还是旧版（api < 2）——
  用本包里的 page-R1.1.0.html 走「页面热更」上传一次即可。

本版主要更新（相对 fw R1.0.11 + page R1.0.26）
------------------------------------------------
- A1 屏改为**四档驱动模式**（默认「方案D 相位1」，与卖家可用固件同映射）：
  A1 栅极按两 bank 交错布线，源行必须交错送出，1:1 覆盖 552 条可见栅极，
  零重采样、无白边；同时修正行内方向 → 解决图像左右镜像与照片条纹噪点。
- 帧格式升级到 api 2：允许 800×600 原生载荷（120000 B）与版本 2 帧头；
  固件仍兼容旧 768×552 / 版本 1 帧。
- 创作页面编辑空间随 A1 驱动档在 552×768 ↔ 600×800 之间切换，
  已存工程的文字坐标/字号/换行宽/留白按比例迁移。
- A0 与 A1.1 屏路径零改动（映射、几何、行内变换均未触碰）。
