墨印 MoInk 一键刷机包（在其他电脑上刷机用）
基线版本：fw R1.1.1 + page R1.1.1（2026-09-23，api 保持 2）
================================================

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.1.1_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.1.1_app.bin     OTA 升级包（设备已能开机时，在网页「设置」里上传）
  page-R1.1.1.html         创作页面（网页「设置」里「页面热更」上传，免刷机）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）

首次使用步骤
------------------------------------------------
1. 双击 MoInk一键刷机.bat。如果这台电脑没有 Python，
   会询问「是否自动下载并安装」，输入 y 回车即可：
   自动从 python.org 下载官方安装包静默安装（约 25 MB），装完自动继续。
   已装过 Python 的电脑会直接进入下一步。
   第一次刷机还会自动 pip 安装 esptool，之后不再需要。

2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。

3. 双击 MoInk一键刷机.bat，等它自动选串口、自动刷写（约 1~2 分钟）。
   脚本只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）会自动跳过。

4. 看到 [OK] 刷机完成即可。设备重启后：
   手机 Wi-Fi 连接热点 MoInk-XXXX（默认开放）→ 自动弹出控制页，
   或浏览器打开 http://192.168.4.1

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  网页烧录器（WebSerial）会卡死在 "Stub running..."，一个字节都写不进。
- 刷整包会整体覆盖设备上的现有固件。
- 如果卡死或失败：拔插一次 USB，然后在本目录打开命令行运行：
      python flash_on_pc.py --no-stub
- 查看本机全部串口：
      python flash_on_pc.py --list

刷完验证
------------------------------------------------
1. 手机 Wi-Fi 出现 MoInk-XXXX，连接后能打开控制页。
2. 控制页「设置」里设备状态应显示：固件 R1.1.1 / 页面 R1.1.1 / 接口 2。
3. 传一张图，屏幕应在约 15~25 秒内完成刷新。

★ 推荐：刷机时勾选「同步更新页面」
------------------------------------------------
控制页「设置 → 系统维护与升级 → ① 固件」下方新增了一个复选框
「同步更新页面」，建议【勾选】后再点「上传固件并重启」。

为什么：设备会优先显示"曾经上传过的页面"（通过网页热更传进去的页面），
刷固件并不会替换它。不勾选的话，升级完固件后界面可能还是那份旧页面，
看起来像"固件没生效"（此时可在设备信息里看到「页面」版本号还是旧的）。

勾选后，固件在校验通过、确定要重启时，会一并清掉那份旧页面的标记，
重启后直接使用新固件自带的新页面 —— 一次操作把固件和页面都换新。

- 该复选框默认不勾，行为与上一版完全一致；
- 若你特意想保留自己热更的页面，就不要勾选。

★ A1 屏四档驱动验收（FB-010）
------------------------------------------------
适用：A1 批次屏（编号 A1，图像左右镜像 / 照片有细密条纹的那批）。
若你的屏是 A0（一直显示正常）或 A1.1（中间有黑线），不用管这一节。

操作路径：控制页「设置」→「屏幕设置」→「屏幕」选 A1
          → 下方出现「A1 驱动」下拉（共 4 档）。
（没连设备、直接本地打开页面时也能看到这个下拉，方便先熟悉界面。）

用同一张【非对称测试图】逐档上传、逐档拍照记录（推荐素材：
samples/FB-010/测试图片/01_非对称方向图.png，图上带文字 + 箭头 + 四角编号）。

  档位                        期望结果
  --------------------------  --------------------------------------------
  方案D 相位1（默认）          ★ 正解。图像完整、方向正确、无穿插条纹。
                              后续日常就用这一档。
  方案D 相位2                 若「方案D 相位1」能显示但上下半屏内容对调/错位，
                              改试这一档，二选一定案。
  方案A 原生800×600           诊断档。按可见区裁切（右下内容被切掉），
                              画面会明显不对，仅作对照，不用它出图。
  方案A′ 原生800×600          诊断档。同上几何，仅映射改交错。

判定要点：
  - 方向：图上文字可读、四角编号位置正确 → 方向对；
          文字左右反 → 勾选「左右镜像」再试；仍不对请反馈照片。
  - 穿插条纹：画面没有"上下半屏互相穿插""细密横纹" → 正确；
              若相位1 有、相位2 无（或反之）→ 定相位2。
  - 白边/裁切：可见区应被画面铺满、无白边、无内容被裁掉。
  - 选中档位后点「保存」，改档即时生效（无需重刷固件）。

本版主要更新（相对 fw R1.1.0 + page R1.1.0）
------------------------------------------------
- 新增「同步更新页面」选项：刷固件时可一并把控制页切到新版，
  不必再手动走一次「页面热更」。
- A1 驱动档位下拉文案精简为「方案D 相位1 / 方案D 相位2 /
  方案A 原生800×600 / 方案A′ 原生800×600」，并移除下方整段原理说明。
- 页面离线预览（未连设备直接打开）也能显示 A1 档位下拉与对应编辑空间。
- api 保持 2：帧格式、色彩、几何、算法均无改动，A0 / A1.1 路径零影响。

页面与固件版本关系
------------------------------------------------
- 若页面显示不出「A1 驱动」下拉，说明设备上那份页面还是旧版：
  用本包里的 page-R1.1.1.html 走「页面热更」上传一次，或者
  直接勾选「同步更新页面」重刷一次固件。
