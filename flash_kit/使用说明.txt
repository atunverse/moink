墨印 MoInk 一键刷机包
版本：R1.4.0（2026-11-17 正式版，api 保持 2）
================================================

本版主要变化（R1.3.7 之后的一次大更新）：
  ① 控制页整体重做 —— 手机照片编辑器形态：顶栏 + 相纸画布 + 底栏四工具
     （构图 / 调色 / 特效 / 保存），面板顶部抓手可下拉收起。
  ② 新增「便签」模式 —— 六种版式（待办 / 备忘 / 康奈尔 / 看板 / 画报 /
     票根挂件）× 六套四色主题，纯黑白黄红、零灰阶。
  ③ 模板与贴纸全部重写 —— 六种现场绘制边框（细边框 / 拍立得 / 拼图 /
     票据 / 胶片等），贴纸分图标（单色换色）/ 表情 / 上传图片三类。
  ④ 帧数据改流式 —— 删掉 120 KB 静态帧缓冲，运行期可用堆 45 KB → 154 KB，
     解决「刷新几次就打不开网页」。
  ⑤ 自锁三修 —— 刷完机按一下就能开机；网页「保存并重启」不再关机；
     USB 轮询只留给 FPC 老排线。
  ⑥ 控制页随固件发布 —— 不再单独提供页面文件，上传入口只收 .bin。
     web 分区并入 OTA 槽（各 1408 KB），已有轮播图不丢。

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.4.0_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.4.0_app.bin     OTA 升级包（设备已能开机时，在网页里上传）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）
  ※ 本版起不再提供独立的页面文件（page-*.html），控制页随固件一起更新。

怎么升到本版
------------------------------------------------
★ 本版分区表有变（web 并入 OTA 槽），从更早版本升级必须整包线刷。
  R1.4.0 的帧格式与 api=2 没变，整包刷完后设置与轮播图保留。

★ 分区表有变，本版首次升级请优先用方式 B（整包线刷）。
  以后同版本内重新升级，才可用方式 A（网页 OTA）。

方式 A：网页 OTA（仅适用于已刷过 R1.4.0、需重新升级的情况）
  1. 控制页「设置 → 更新和恢复」，选 moink_R1.4.0_app.bin
  2. 等设备重启完成（约 1 分钟），版本显示 R1.4.0

方式 B：整包刷写 / 首次使用 / 从 R1.3.x 等旧版本升级
  1. 双击 MoInk一键刷机.bat。没装 Python 会询问是否自动安装，输入 y 回车。
  2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。
  3. 脚本自动选串口、自动刷写（约 1~2 分钟）。
     只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）自动跳过。
  4. 看到 [OK] 刷机完成即可。手机 Wi-Fi 连 MoInk-XXXX（默认开放）→
     浏览器打开 http://192.168.4.1

操作要点（简要）
------------------------------------------------
· 控制页底栏四工具：构图（旋转/裁剪/白边）、调色（四预设+高级）、
  特效（文字/模板/贴纸/日期）、保存（上传刷新/存图库/存远程/导出手机）。
· 顶栏「便签 / 拍立得」切换模式，便签底栏变为 内容/版式/配色/保存。
· 按键：单击=唤醒（不切图），双击=切下一张轮播图，长按 20 秒=恢复出厂。

★★★ 关于自锁（电池供电必须知道）
------------------------------------------------
· 冷启动把 GPIO5 与 GPIO1 都当候选脚读，无论 GPIO 预设是哪一档都能按一下开机。
· 电池供电时 GPIO2 维持高电平（MOS 导通）自锁；USB 供电时不导通，防 5V 倒灌电池。
· 只有「接法 = 排线 + 老排线」才在自锁态每 200ms 采样检测 USB 插入。
  整合板 / 默认档 / 新排线不再轮询（更省电，插 USB 也不会误切供电）。
· 网页「保存并重启」、OTA 后重启、长按恢复出厂重启，都不会掉电。
· 已知限制：panic / 看门狗复位仍会断电（芯片自己复位，软件来不及保持电平），
  要彻底解决需硬件侧加 RC 保持或双稳态。

★ 排线接法（与 R1.3.1 一致）
  信号        排线档        默认档
  ADC          GPIO0         GPIO0
  KEY（唤醒）   GPIO1         GPIO5
  LOCK（自锁）  GPIO2         GPIO2   （固定）
  BUSY         GPIO3         GPIO10
  RST          GPIO4         GPIO3
  DC           GPIO5         GPIO1
  CS           GPIO6         GPIO7
  SCK          GPIO7         GPIO4
  DIN(MOSI)    GPIO10        GPIO6

★ GPIO 设置四档：默认 / 排线 / 整合板 / 自定义。改完点「保存并重启」才生效。
※ 改错导致屏不亮：按住唤醒键 20 秒恢复出厂。

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  WebSerial 会卡死在 "Stub running..."，一个字节都写不进。
- 卡死或失败：拔插一次 USB，本目录命令行运行 python flash_on_pc.py --no-stub
- 查看全部串口：python flash_on_pc.py --list
- 设备深睡后 USB 串口会消失，刷机前先按一下按键唤醒（或 RTS 硬件复位，不用拔插）。

★ 关于电量显示（分压比写死在固件里）
------------------------------------------------
本包按 ×2.0 分压标定 —— 100k:100k 与 1M:1M 都能直接用。
一次请求连采 12 次取中位数，用极差判断悬空。
⚠️ 新排线 ADC 接在 VSYS：插 USB 时读数接近 5V 属正常（读的是母线不是电芯）。
⚠️ 若用 1M:1M（源阻抗约 500 kΩ），ADC 端建议并联 100 nF 到地。
